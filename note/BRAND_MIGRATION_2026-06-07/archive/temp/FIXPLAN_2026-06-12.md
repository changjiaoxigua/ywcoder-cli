**文件**：`src/utils/localInstaller.ts:19`

**现状**：`getLocalInstallDir()` 是模块私有函数，但 P2/P3/P4 都需要它返回的目录路径（`~/.ywcoder/local`）。

**改动**：在 `function` 前加 `export`。

```ts
// before
function getLocalInstallDir(): string {

// after
export function getLocalInstallDir(): string {
```

> 注：`getLocalInstallDir()` 内部用 `getYwCoderConfigHomeDir()`，路径已是正确的 `~/.ywcoder/local`。

## P2：doctorDiagnostic.ts — alias 路径修复

**文件**：`src/utils/doctorDiagnostic.ts:473,479`

**现状**（两处 fix 字符串）：
```ts
fix: `Alias exists but points to invalid target: ${existingAlias}. Update alias: alias claude="~/.claude/local/claude"`,
fix: 'Create alias: alias claude="~/.claude/local/claude"',
```

**背景**：
- 本地安装的 wrapper 脚本名称仍为 `claude`（`localInstaller.ts:78`），`which('claude')` 检测逻辑保持不变。
- 路径随 `getLocalClaudePath()` 走，已正确指向 `~/.ywcoder/local/claude`。

**需要新增 import**：在已有的 localInstaller import 块里加 `getLocalClaudePath`。

```ts
// before
import {
  getShellType,
  isRunningFromLocalInstallation,
  localInstallationExists,
} from './localInstaller.js'

// after
import {
  getLocalClaudePath,
  getShellType,
  isRunningFromLocalInstallation,
  localInstallationExists,
} from './localInstaller.js'
```

**改动字符串**：

```ts
// before (line 473)
fix: `Alias exists but points to invalid target: ${existingAlias}. Update alias: alias claude="~/.claude/local/claude"`,

// after
fix: `Alias exists but points to invalid target: ${existingAlias}. Update alias: alias claude="${getLocalClaudePath()}"`,
```

```ts
// before (line 479)
fix: 'Create alias: alias claude="~/.claude/local/claude"',

// after
fix: `Create alias: alias claude="${getLocalClaudePath()}"`,
```
