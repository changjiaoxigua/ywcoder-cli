### 市场通知说明

#### 修复前的问题流程（历史记录）

`src/hooks/useOfficialMarketplaceNotification.tsx` 触发的通知并非来自一个"已禁用就完全不运行"的功能。修复前实际流程为：

1. 启动时 `REPL.tsx` 调用该 hook，hook 调用 `checkAndInstallOfficialMarketplace()`。
2. `checkAndInstallOfficialMarketplace()` 先检查 `shouldRetryInstallation()`；若从未尝试过，则进入 `try` 块。
3. `try` 块内才调用 `isOfficialMarketplaceAutoInstallDisabled()`。该函数当前硬返回 `true`（即永久禁用官方市场）。
4. 禁用分支会调用 `saveGlobalConfig(...)` 把 `policy_blocked` 状态写进全局配置文件；若写入因权限问题失败，异常进入外层 `catch`，再次尝试写入，再次失败则 `configSaveFailed = true`。
5. hook 弹出通知：`Failed to save marketplace retry info · Check ~/.claude.json permissions`（路径错误 + 品牌暴露）。

#### 修复后的实际流程（✅ 已完成·2026-06-14 批次三）

改动文件：`officialMarketplaceStartupCheck.ts` + `useOfficialMarketplaceNotification.tsx`

1. 启动时调用 `checkAndInstallOfficialMarketplace()`。
2. 函数**第一行**调用 `isOfficialMarketplaceAutoInstallDisabled()`（当前硬返回 `true`）。
3. 立即返回 `{ installed: false, skipped: true, reason: 'policy_blocked' }`，**不读 config、不写 config**。
4. hook 收到结果：`configSaveFailed` 未定义，`installed` 为 false，`reason` 为 `'policy_blocked'`（非 `'unknown'`），三个通知分支均不满足条件，**不弹任何通知**。

通知文案同步修正（将来恢复启用时生效）：

- 路径：由 `getConfigHomeDisplayPath()/.config.json`（legacy 用户路径错误）改为 `displayGlobalConfigFile()`（对 `getGlobalClaudeFile()` 做 tilde 折叠，新装显示 `~/.ywcoder/.config.json`，legacy 显示 `~/.claude.json`）
- 成功：`YwCoder marketplace installed` → `Official marketplace installed`
- 失败：`Failed to install YwCoder marketplace` → `Failed to install official marketplace`

#### 将来恢复启用方案

恢复时需按顺序处理以下几点：

1. **解锁 `isOfficialMarketplaceAutoInstallDisabled()`**（`officialMarketplaceStartupCheck.ts:47–51`）：删除 `return true` 硬编码，恢复 `return isEnvTruthy(process.env.CLAUDE_CODE_DISABLE_OFFICIAL_MARKETPLACE_AUTOINSTALL)` 的注释行。

2. **处理历史用户的 `policy_blocked` 状态**：已运行过旧版的用户，全局配置里存有 `officialMarketplaceAutoInstallFailReason: "policy_blocked"`，导致 `shouldRetryInstallation()` 永远返回 false，重新启用后市场不会自动安装。解决方案二选一：
   - 在版本升级检测逻辑里清除 `officialMarketplaceAutoInstall*` 系列字段；
   - 或在 `shouldRetryInstallation()` 里对 `policy_blocked` 状态改为"允许在下一版本重试"（加版本号比较）。

3. **确认 `OFFICIAL_MARKETPLACE_NAME` / `OFFICIAL_MARKETPLACE_SOURCE`**：若启用的是 YwCoder 自建市场而非 Anthropic 官方，需同步更新这两个常量及相关 registry URL。

4. **通知文案与路径无需再改**：本次已完成去标识（`official marketplace`）和路径动态化（`displayGlobalConfigFile()`）。
