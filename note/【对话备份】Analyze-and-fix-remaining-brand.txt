  Claude Code 文档链接。

  ---
  ❌ 不能只改文本：改了会造成功能误导

  tipRegistry.ts 中 4 条 tip 的问题不是品牌名，而是这些 tip 指向 Anthropic
  专有功能：

  ┌──────────────────┬─────────────────┬─────────────────────────────────────┐
  │      Tip ID      │      内容       │                问题                 │
  ├──────────────────┼─────────────────┼─────────────────────────────────────┤
  │ desktop-app      │ clau.de/desktop │ 这是 Anthropic 的 Claude Desktop    │
  │                  │                 │ 下载链接，YwCoder 不存在            │
  ├──────────────────┼─────────────────┼─────────────────────────────────────┤
  │ desktop-shortcut │ /desktop 命令   │ 该命令会尝试连接 Claude Desktop     │
  │                  │                 │ 协议，在 YwCoder 中无效             │
  ├──────────────────┼─────────────────┼─────────────────────────────────────┤
  │ web-app          │ clau.de/web     │ Anthropic 云运行功能，YwCoder       │
  │                  │                 │ 不存在                              │
  ├──────────────────┼─────────────────┼─────────────────────────────────────┤
  │ mobile-app       │ /mobile 命令    │ 打开 Claude 手机 app，YwCoder       │
  │                  │                 │ 不存在                              │
  └──────────────────┴─────────────────┴─────────────────────────────────────┘

  如果把这 4 条改成 YwCoder Desktop / YwCoder on your
  phone，用户跟着做会直接报错或访问 Anthropic 服务。正确做法是禁用这 4 条
  tip，而不是替换品牌名。 最简方式：将其 isRelevant 改为 async () =>
  false，或直接删除。

  ---
  ❌ 改了会破坏 Claude 生态兼容性

  src/commands/init.ts 是最敏感的一处，涉及两个层面：

  层面1：生成的 CLAUDE.md 文件头
  This file provides guidance to Claude Code (claude.ai/code) when working with
  code in this repository.
  这是 Anthropic 生态的标准 CLAUDE.md 文件头。OMC (oh-my-claudecode)、Cursor
  Rules、GitHub Copilot 等工具在解析项目配置时，会识别这个文件头作为 AI coding
  配置文件的标志。改成 YwCoder 后，部分工具可能不识别此文件，导致 OMC
  skills/hooks 等生态工具失效。建议保留此文件头不变。

  层面2：NEW_INIT_PROMPT 中的插件引用
  /plugin install frontend-design@claude-plugins-official
  /plugin install playwright@claude-plugins-official
  /plugin install skill-creator@claude-plugins-official
  这些是 Anthropic 官方插件注册中心的地址。即便把品牌名改成 YwCoder，这些
  /plugin install 指令仍然指向 Anthropic
  的服务，改品牌名会造成文本与实际功能的割裂。init.ts 的 prompt
  内容建议整体不动，或者做专门的功能层清理，而非品牌文字替换。

  ---
  ❌ 整个命令应禁用，而非改名

  src/commands/stickers/index.ts — /stickers 命令的实际功能是打开 Anthropic
  周边商品订购页面。把描述改成 Order YwCoder stickers 会让用户点进去发现是
  Anthropic 的商店。应禁用整个命令（在 commands.ts 中移除注册，或将 isRelevant
  返回 false），而不是改名。

  Task 3.1 — pathValidation.ts（5处安全校验提示）

  触发场景：AI 尝试执行带 cd、带
  flag、或写入受限路径的命令时，弹出权限确认框中的说明文字。

   only ${ACTION_VERBS[command]} the allowed working directories..." —

  4. 与第2条相同情况的输出重定向版本
  5. "Output redirection to '${resolvedPath}' was blocked. For security, Claude
  Code may only write to files in the allowed working directories..." —

  - ✅ 纯文本替换，零功能风险
